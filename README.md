# Python for Mathematics — Exercise Solutions

This repository collects my solutions to exercises from Julien Guillod’s *Python Programming for Mathematics*, based on the [French version of his GitHub repository](https://github.com/guillod/python/tree/fr).

The Jupyter notebooks document my progress in using Python to explore mathematical problems, implement algorithms, and carry out numerical experiments.

All exercise statements originate from Julien Guillod’s collection. The solutions in this repository are my own and may contain errors.
